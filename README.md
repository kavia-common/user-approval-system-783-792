# user-approval-system-783-792 (dashboard_frontend)

React frontend for the Social Dashboard.

## Quickstart

1) Configure environment:
   - Copy dashboard_frontend/.env.example to dashboard_frontend/.env
   - Set REACT_APP_API_BASE_URL (default http://localhost:3001)

2) Install and run:
   cd dashboard_frontend
   npm install
   npm start

Runs at http://localhost:3000

See dashboard_frontend/README.md for feature details and E2E flow verification.
